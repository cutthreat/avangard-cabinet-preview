# Макет личного кабинета Avangard

Публичная версия локального макета для просмотра интерфейса. Откройте [страницу макета](https://cutthreat.github.io/avangard-cabinet-preview/?example=odoo#payments). Внизу страницы можно переключать наборы данных.

Интерфейс собран из статических HTML/CSS/JS, серверные операции отсутствуют.
